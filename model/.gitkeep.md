# /model

Эта директория будет заполнена автоматически при первом Publish из Archi через coArchi.

Структура после Publish:
```
model/
├── folder.xml
├── elements/
│   ├── ApplicationComponent_*.xml
│   ├── BusinessService_*.xml
│   ├── DataObject_*.xml
│   └── ...
├── relations/
└── views/
```

Не редактируйте XML-файлы вручную — работайте только через Archi.
